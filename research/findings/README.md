# Research findings

Updated 26 September 2026. The [Astra ledger](../../ASTRA_RESEARCH_LEDGER.md)
remains the authoritative change history. This directory collects the completed
results and the follow-up analysis requested by the project owner.

- [Complete component results](component_results.md): all 12 models, five seeds,
  200 epochs each on L4; interpretation and verification references.
- [All 60 runs as CSV](component_runs.csv): validation and test metrics, confusion
  counts, thresholds, parameter counts, timing, GPU memory and artifact hashes.
  Metrics use fractions, not percentages, in this CSV.
- [Original aggregate JSON](component_summary.json): byte-identical copy of the
  verified summary, including all paired comparisons and resource summaries.
- [Does more data make memory useful?](memory_and_data_scale.md): source research,
  implementation audit, measured limitations and proposed experiments.
- [Memory/data audit JSON](memory_horizon_audit.json): reproducible diagnostics
  generated by `../../audit_memory_horizon.py`, which performs no training.
- [Temporal CNN study status](cnn_study_status.md): 40 registered runs on one
  L4, causal CNN/hybrid models, optimized rehearsal, concurrency measurement and
  GPU telemetry. Results are complete and independently audited; kept separate
  from the completed 60-run study.
- [Completed temporal CNN findings](../../TEMPORAL_CNN_FINDINGS.md): all 40 runs,
  standalone CNN and hybrid results, capacity/causality interpretation and next
  controlled experiments.

Original checkpoints, predictions, epoch losses and source snapshots stay in
`../../artifacts/components_200e_v1/`. These links and exports preserve their
identity rather than moving or rewriting the original experiment artifacts.
